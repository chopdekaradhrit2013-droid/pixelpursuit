# World maps

Full 3x3 island archipelago for Pixel Pursuit.

- `world-day.jpg` / `world-day.webp` — daytime
- `world-night.jpg` / `world-night.webp` — nighttime

Each of the 9 tiles is its own island with water channels between them.

Layout (same for day and night):

```
NW forest path     | N manor gardens      | NE walled courtyard
W  cliff + cave    | CENTER crossroads    | E  fields / camp
SW beach campfire  | S  palm wreck isle   | SE lily ponds
```

Source images imported 2026-08-26. No engine assets — raw map art only.
