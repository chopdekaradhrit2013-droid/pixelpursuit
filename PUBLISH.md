# Publish Pixel Pursuit

This is a browser game. Ship it like one.

## 1. Live URL (required)
Lovable already hosts a build:
https://pixelpursuit.lovable.app

For a clean public URL on Vercel:
1. Import `chopdekaradhrit2013-droid/pixelpursuit` in Vercel.
2. Framework: Vite. Build `npm run build`. Output is whatever TanStack Start/Nitro emits (Vercel detects it).
3. Assign `pixelpursuit.vercel.app` or a custom domain.

## 2. itch.io page (best storefront for this game)
1. Create a game: https://itch.io/game/new
2. Classification: Games
3. Kind of project: HTML
4. Either embed the live URL or upload the `dist` folder as a zip.
5. Price: Free or PWYW.
6. Cover: 630×500, dark jungle, survivor + hooded hunter.
7. Genre tags: Survival, Action, Pixel Art, Browser, Horror-lite.

### Page text (paste this)

Title: Pixel Pursuit

Short: Recover the beacons. Break the hunter's sight. Extract the cave before the clock dies.

Body:
You wake on a tiled jungle island that changes when night falls. Three signal beacons are still alive. A hooded predator is already walking the patrol loop.

Hide in swamp fog. Do not sprint unless you must. When the last beacon lights, run the southwest cave.

Standard is a readable hunt. Nightmare is not.

WASD to move. Shift to sprint. Works on phone.

## 3. What “publishable” means here
Shipped:
- complete loop (title → hunt → win/lose)
- two difficulties
- mobile + keyboard
- AI with more than one state
- shareable URL

Not Steam Early Access, not a 12-hour campaign. Do not wait for that. Put the link on itch today.
